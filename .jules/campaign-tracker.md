# Campaign Tracker: Coin Flipper Incremental

This tracker records progress across autonomous Jules persona sessions.

## Project Structure
- `cmd/server/main.go`: Go HTTP server embedding `web/` static files.
- `web/`: Game frontend (HTML, Canvas coin renderer, Web Audio synthesizer, game logic).

## Campaign Goal
Build a rich incremental coin-flipping game with:
1. Canvas 2.5D coin flip physics and procedural Web Audio feedback.
2. Unique unlocks (Coin alchemy, magnetic tables, automation, streak bets).
3. Meta Layer 1: City Relocation (Monte Carlo, Wall Street, Tokyo, Geneva).
4. Meta Layer 2: World Domination (Buy continents, World Bank, planetary mint).
